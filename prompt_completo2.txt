Descripción general del proyecto
El proyecto final consiste en desarrollar un videojuego en consola utilizando programación
híbrida con C y NASM de 64 bits. El juego llevará por nombre:

BitQuest: Explorador de matrices con C y NASM
El videojuego deberá representar un laberinto mediante una matriz grande. El jugador se
moverá dentro del mapa, recolectará monedas, buscará una llave, abrirá una puerta y llegará
a una salida para avanzar de nivel.

A diferencia de un juego donde se muestra todo el mapa en pantalla, en este proyecto el
mapa completo será más grande que la zona visible. Por ejemplo, cada nivel podrá tener una
matriz de 60 x 60, pero en la pantalla solo se mostrará una ventana de 20 x 20. Cuando el
jugador se mueva, la vista deberá desplazarse para mostrar la zona cercana al jugador.

El objetivo principal es reforzar el uso de matrices, funciones, paso de parámetros, compilación
híbrida, manejo de memoria, ciclos, condiciones y llamadas a rutinas escritas en ensamblador
desde un programa en C.

Objetivo del proyecto
Desarrollar un videojuego en consola que integra código en C con rutinas escritas en NASM
de 64 bits. El programa deberá demostrar que el estudiante comprende cómo representar
información mediante matrices, cómo recorrer la memoria, cómo validar movimientos dentro de
un mapa y cómo llamar funciones en ensamblador desde un programa escrito en C.

Al finalizar el proyecto, el estudiante deberá ser capaz de:

Representar un mapa mediante una matriz de caracteres.
Mostrar únicamente una parte visible de una matriz más grande.
Controlar el movimiento de un jugador dentro de un laberinto.
Validar paredes, puertas, llaves, monedas y salida
